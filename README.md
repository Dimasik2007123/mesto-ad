# Место (Mesto)

Адаптивный одностраничный сайт для публикации фотографий с возможностью ставить лайки и удалять свои карточки.

## Опубликованная версия

🌐 **https://Dimasik2007123.github.io/mesto-production/**

## Установка и запуск локально

1. Склонируйте репозиторий:

```
  git clone https://github.com/Dimasik2007123/mesto-ad.git
  cd mesto-ad
```

2. Установите зависимости:

```
  npm install
```

3. Запустите проект в режиме разработки:

```
  npm run dev
```

4. Собрать production-версию:

```
  npm run build
```

5. Опубликовать на GitHub Pages (в репозиторий mesto-production):

```
  npm run deploy
```
